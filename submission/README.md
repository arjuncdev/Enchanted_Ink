# Enchanted Ink submission artifacts

The IEEE-style report and source package are in `Enchanted_Ink_IEEE_Report/`.

- Submission/print copy: `Enchanted_Ink_IEEE_Submission_Report.pdf`
- Editable Overleaf source: `Enchanted_Ink_IEEE_Report/main.tex`
- Uploadable Overleaf bundle: `Enchanted_Ink_IEEE_Overleaf_Project.zip`

The report evaluates the actual fine-tuned TrOCR checkpoint on 35 held-out lines. The package includes aggregate metrics, PNG figures, and saved training arguments, but excludes source images and per-line predictions.
